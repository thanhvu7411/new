# Lamda Extra – TOC side column patch

 Patches for `lamda-extra` TOC assets used on anhthuy2:

- `assets/toc.js` – auto TOC floats beside `#post_content` (sticky while scrolling that block); headings from `.elementor-widget-theme-post-content`
- `assets/toc.css` – floating side-column styles

Deployed to: `wp-content/plugins/lamda-extra/assets/`
